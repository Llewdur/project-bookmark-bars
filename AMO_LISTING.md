## Full Description

```
## Never lose track of your bookmarks again

Are you tired of having one massive bookmark bar mixing work, personal projects, research, and hobbies all together? Project Bookmark Bars lets you create unlimited bookmark bars—one for each project or context—and switch between them instantly.

Perfect for developers, researchers, students, freelancers, and anyone who juggles multiple projects or contexts.

## Key Features

✅ **Multiple Bookmark Bars** - Create unlimited bars, one for each project
✅ **Collapse & Expand** - Keep your sidebar clean by hiding bars you're not using
✅ **Lightning-Fast Switching** - Keyboard shortcuts to jump between bars instantly
✅ **Drag & Drop Everything** - Move bookmarks between bars, reorder within bars, and import entire folders at once
✅ **Quick Add** - One-click button to bookmark your current tab
✅ **Open All** - Open every bookmark in a bar with one click
✅ **Persistent Sidebar** - Always visible but never intrusive
✅ **Export & Import** - Back up your data as JSON files
✅ **Dark Mode** - Automatically matches your system theme
✅ **Privacy First** - No tracking, no cloud sync, all data stays on your device

## Why This Extension?

**Problem:** Firefox's native bookmarks force everything into one toolbar. Other bookmark extensions either corrupt your data (check the reviews!) or sync across devices causing conflicts.

**Solution:** Project Bookmark Bars stores data separately in safe extension storage—no risk of corrupting your native bookmarks. It's designed from the ground up for multi-project workflows.

## Common Use Cases

**Developers:** One bar for each project (Frontend, Backend, DevOps, etc.)
**Researchers:** Separate bars for different research topics
**Students:** One bar per course or subject
**Freelancers:** Client-specific bookmark bars
**Job Seekers:** Job boards, applications, networking
**Content Creators:** Research, tools, inspiration, admin

## Quick Start

1. Press **Alt+Shift+B** to open the sidebar
2. Click **"+ New Bar"** and name it (e.g., "Work")
3. Add bookmarks using drag-and-drop or the quick-add button
4. Create more bars for different projects
5. Switch between them with **Alt+.** and **Alt+,**

## Keyboard Shortcuts

- **Alt+Shift+B** - Toggle sidebar
- **Alt+.** - Next bar
- **Alt+,** - Previous bar
- **Alt+1/2/3** - Jump to specific bars

All shortcuts are customisable in Firefox settings.

## Safe & Private

- ✅ No tracking or analytics
- ✅ No external servers
- ✅ All data stored locally
- ✅ Open source code (inspect it yourself)
- ✅ No permissions to read your browsing history
```
